Step 2: Prepare the Flutter Project

Open the group's Flutter project or create it if it has not yet been prepared.

Keep the mobile application in the mobile/ folder of the group's GitHub repository. Use meaningful names for screens, models and services.

Check that the application runs in your development environment before implementing the remaining functions.

Step 3: Develop the Approved Screens

Use the wireframes from Unit 3 to build the main mobile screens.

For each screen, implement the required interface elements.

Step 4: Implement Navigation and Forms

Connect the screens so users can move through the mobile application.

Add appropriate form validation. For example, a user should receive a helpful message when a required field is empty.

Short example: A customer opens the appointment form, enters the required details and selects Submit Request. The application checks the information before attempting to save it.

The exact navigation and validation must follow your project's requirements.

Step 5: Connect Flutter to the Shared Supabase Backend

Use the same Supabase project configured in Activity 4.1.

Install and configure the supabase_flutter package, initialise the client and connect the required application functions to the approved database tables. Follow the official quickstart for the current setup steps.

Step 6: Implement the Main Mobile Functions

Implement the mobile functions identified in Step 1.

Where authentication is required, connect the sign-in process to Supabase Authentication and make sure users can access only the information and functions permitted by their role.

For each function, check that the user can complete the intended process from beginning to end.

Activity Outcome

A working Flutter mobile application with the approved screens, navigation and main functions implemented.

The mobile application must connect to the shared Supabase backend and be ready for integration with the ASP.NET web application.

Before Moving On

Confirm that the group has:

  • implemented the approved mobile screens and navigation;
  • developed the required forms and mobile functions;
  • connected Flutter to the shared Supabase backend;
  • checked the main functions using suitable test data;
  • retained evidence of the working mobile application;
  • committed relevant code to GitHub; and
  • updated Microsoft Project and the Project Progress Tracker.
