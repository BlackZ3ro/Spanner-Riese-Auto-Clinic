# Phase 2 Documentation (Unit 3 — System Architecture and Design)

This folder holds the Assessment 2 portfolio (15 credits, 30%): system
architecture, UML diagrams, ERD, interface designs, stakeholder feedback,
and the updated planning/tracking evidence Unit 3 asks for.

**Note on approach:** by the time Unit 3 started, Gary had already built most
of the working prototype (M0–M8, see `web/README.md` and `web/CLAUDE.md`).
So instead of designing on paper first, these documents describe the system
**as it was actually built and verified live** — the architecture, ERD and
sequence diagrams below are grounded in the real Supabase schema and the
real Postgrest/RPC calls, not a guess. That's a stronger and faster path to
an accurate Phase 2 submission, but it means the group should be honest in
the reflection that design followed implementation on the web side, and
explain why (stakeholder urgency, iterative approach) rather than claim
design-first.
