# Stakeholder Interview Transcript

**Date:** 19 August 2026  
**Stakeholder:** Michael Riese (Owner / Head Mechanic – Riese Auto-Clinic)  
**Interview Type:** Formal structured interview  

---

### Q1  
**So you would like us to make your life a bit easier, how can we do that for you?**

**A1:**  
We would like an app for mobile and a desktop/web version that can keep track of all the stock we keep, where we got the parts, and their costs.

---

### Q2  
**Okay, that makes sense. And I would assume you would want the app and web version to talk to each other and keep track of the same stock and things?**

**A2:**  
Yes. We’d like all the mechanics to be able to see what we have available, what needs to get bought, and so on, but also so that the admin personnel can also keep track of the money spent on each job that comes in.

---

### Q3  
**Alright, so we need to develop a back end database that tracks parts, and for which jobs they’re being used for. Might I also make a suggestion? If we are tracking the parts, why not track what types of jobs is being performed on different vehicles? Have a central tracking/management system?**

**A3:**  
That would be perfect. Having admin and the mechanics all stay in the loop and on the same page with what is being done and the costs involved with it as well.

---

### Q4  
**That is what I had in mind as well. We can even make it so that every mechanic working on a vehicle is able to log their labour time on the app, admin can see it, and when developing the invoice, have a clear track of who did what on which vehicle and for how long, if that is what would help as well?**

**A4:**  
That would honestly help us a lot with paperwork and unnecessary admin work.

---

### Q5  
**Is there anything else we can do for you or that we can include into this system that would improve your situation?**

**A5:**  
Yes, actually, if it would be possible, to have the system itself export an invoice after all the work is done on a vehicle, which includes all the labour and cost price.
